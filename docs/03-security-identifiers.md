# Security Identifiers (SIDs)

## Overview

Security Identifiers (SIDs) are unique values assigned by Windows to security principals such as users, groups, computer accounts, and service accounts. Windows uses SIDs internally to identify these objects instead of relying on usernames, which can change over time. Because usernames can be renamed or duplicated across different systems, Windows uses SIDs as permanent identifiers. This allows permissions, ownership, and access control to remain consistent even if an account's display name changes. Each time when user logs in to account , the session is created and this session contains SIDs,
User rights and other important features belonging to user. 

## SID vs Username
a username is a human-readable identifier that users type during login.
a SID is a machine-readable identifier generated by Windows and permanently assigned to a security principal.
Although usernames may change, the SID remains the same. Windows uses the SID internally when managing permissions and access control.

## Common Well-Known SIDs

S-1-5-113 	Local account
S-1-5-2    	Network
S-1-5-6 	Service
S-1-5-11 	Authenticated Users 
S-1-5-19 	NT Authority (LocalService)
S-1-5-domain-512 	Domain Admins
S-1-5-domain-514 	Domain Guests
